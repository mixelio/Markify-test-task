## Тестове завдання від Galaktica

<p style="color:#585858">
    Проєкт Markify створено для демонстрації моїх вмінь у створенні веб-стрінок і розуміння таких технологій, як HTML, SCSS, JavaScript. При створенні проєкту було приділено увагу адаптивності, валідності, доступності. Веб-сторінка корректно відображається у найпоширеніших браузерах.

## Технології
- HTML
- SCSS
- JavaScript
- Vite
- GitHub Pages

## Особливості
- Плавна анімація при наведенні і переходах
- Навігація поо сторінках резалізована у вигляді вкладок з використанням мінімального JavaScript.

## Запуск проєкту
1. Клонуйте репозиторій:
   ```bash
   git clone
   ```
   
2. Встановіть залежності:
   ```bash
   npm install
   ```
   
3. Запустіть локальний сервер:
   ```bash
   vite
   ```
   
4. Відкрийте браузер і перейдіть за адресою:
   ```
   http://localhost:5173/
   ```
